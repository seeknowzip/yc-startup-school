# Module 2 workbook

Use only when the user requests guided practice, a self-assessment, or a workbook. A module invocation alone does not require an interview.

Use the questions below as a bank, adapting them to the user's stage and already supplied answers. In a guided conversation, ask a manageable question and wait; use an available question interface or ordinary chat. Offering a few answer options can make a question easier to answer. After each answer, respond briefly and connect it to the relevant lecture before moving on. If the user wants the complete worksheet, provide it together. Skip irrelevant or answered questions, and respect requests to stop or change focus.

Read the relevant original material for the concepts used. Separate the user's answers, source-grounded observations, and your interpretation. Summarize supported strengths, gaps, and a useful next action when the requested exercise is complete. Do not invent a readiness score; if a score is requested, explain the rubric, evidence, and uncertainty.

Save only when a file is part of the user's request. Use their destination; if they ask to save without one, use a `yc-startup-school-notes/` folder in the current working directory with a descriptive dated filename. Preserve existing files and distinguish partial answers from a completed exercise. Otherwise finish in conversation.

## Question bank

1. Go through the companies you've worked at (internships count). For each: what did you learn that others don't know / what seemed broken / what did they build in-house that others need? (Jared Friedman)
2. What product or service do you wish someone would build for you? (Jared Friedman)
3. What recent change — a new technology, platform, or regulation — makes something possible now that wasn't before? (Jared Friedman)
4. Which of these filters, if any, have you applied — hard to start (schlep), boring, too ambitious, or existing competitors? If one, give a concrete example of an idea you dismissed this way. (Jared Friedman)
5. Review your current best idea using Jared Friedman's four criteria (how big, founder/market fit, how sure you are the problem is real, new insight), optionally scoring if useful. Which criterion has the weakest evidence and why?
6. Can you name a successful company doing something similar in another geography or market? If your idea is "X for Y," is it solving a real problem or a solution in search of one? (Jared Friedman)
7. Which people with industry expertise — ideally other founders — could you ask what problems they want solved? (Jared Friedman: most people are bad at seeing startup ideas)
8. How many months have you worked on this without it working? Is a little traction or polite feedback keeping you from changing the idea, and is there something you'd be more excited about and better suited to? (Dalton Caldwell, "All About Pivoting")
